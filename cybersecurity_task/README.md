# Phishing Awareness Training

## Overview

Phishing Awareness Training is a simple Python-based quiz application designed to educate users about phishing attacks and cybersecurity best practices. The program presents multiple-choice questions related to phishing, evaluates user responses, and provides a final score with feedback.

## Features

- Interactive command-line quiz
- Multiple-choice cybersecurity questions
- Instant feedback for each answer
- Final score calculation
- Performance assessment based on quiz results
- Beginner-friendly Python implementation

## Technologies Used

- Python 3


## How to Run

1. Ensure Python 3 is installed on your system.
2. Download or clone the project.
3. Open a terminal in the project directory.
4. Run the program:

```bash
python phishing_awareness.py
